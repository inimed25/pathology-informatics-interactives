# Supplemental Question Bank Provenance

These 11 questions were removed from the required lesson flow during the 45-question redundancy audit and were subsequently restored in the optional supplemental question bank. They remain separate from required curriculum counts and completion.

## Module 1.2 — Antimicrobial Decision Support

- Breakpoint update changes the categorical interpretation while the stored MIC remains unchanged. This is a strong application of the same MIC-versus-interpretation distinction already assessed by the retained opening question and revisited in the capstone.

## Module 1.3 — Interfaces and Automation

- Primary function of an electronic instrument-to-LIS interface. Useful foundational recall, but the retained bidirectional-interface question assesses the concept with greater specificity.
- New local organism code requires mapping and end-to-end testing before reporting. Strong scenario, but semantic mapping is already assessed in Module 1.1 and the capstone.
- Distinguishing CLIA/CMS, CAP, and CLSI. Useful factual reinforcement, but less central than applied interface reasoning in the required flow.
- MALDI-TOF reference-database update as an informatics and quality-management change. Strong example of software/database governance, but overlaps the retained mapping-table change-control scenario.
- Rapid molecular panel organism and resistance-gene interpretation. Important, but assessed in greater depth through two linked capstone questions.

## Module 1.4 — Genomics and Bioinformatics

- Distinguishing hybrid capture from hybrid assembly. Valuable terminology check, but less integrative than the retained coverage, mapping, assembly, VAF, and outbreak-analysis cases.
- Governance of an antimicrobial-resistance reference-database update. Strong question, but overlaps the retained reference-genome change-control case and the capstone pipeline-update sequence.

## Module 1.5 — Digital Microbiology

- Extending an image-analysis algorithm from respiratory blood-agar cultures to urine chromogenic-agar cultures. Strong intended-use example, but overlaps the retained post-implementation dataset-shift case.

## Module 1.6 — Public Health Surveillance

- Successful HL7 acknowledgment despite incorrect local-to-standard test mapping. Strong semantic-interoperability scenario, but already assessed in Modules 1.1 and 1.7.
- Genomic similarity as evidence requiring epidemiologic context. Important, but directly assessed in Module 1.4 and the capstone.

The implemented versions are maintained in `src/data/supplementalQuestions.ts`; this document preserves the editorial rationale for keeping each item outside the required flow.
