# Faculty Guide

## Teaching Focus

This lesson introduces microbial genomics as an informatics workflow in which sequencing, bioinformatics, validation, and interpretation must be aligned with the clinical or epidemiologic question.

## Key Teaching Points

- Raw sequence data are not themselves a clinical result.
- Bioinformatics workflows transform sequence data through steps such as quality assessment, alignment or assembly, variant detection, annotation, and comparison.
- Different questions may require different pipelines, databases, parameters, and interpretive thresholds.
- Software versions, reference genomes, databases, and analytical parameters are part of the validated system.
- Genomic relatedness should be interpreted alongside epidemiologic and clinical information.
- Pipeline changes require appropriate validation and change control.

## Discussion Prompts

- How would a bioinformatics workflow for resistance-gene detection differ from one used for outbreak investigation?
- Which components of a microbial genomics pipeline should be included in validation?
- How could changing a reference database alter a result without changing the underlying sequence data?
- Why does genomic similarity alone not prove transmission between patients?
