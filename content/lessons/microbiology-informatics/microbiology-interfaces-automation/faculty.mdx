# Faculty Guide

## Teaching Focus

This lesson introduces the informatics considerations involved in connecting microbiology instruments to laboratory information systems and implementing laboratory automation.

## Key Teaching Points

- Instrument interfaces allow microbiology data to move between analyzers, middleware, the LIS, and downstream clinical systems.
- Successful transmission requires preservation of patient, specimen, test, organism, and result information.
- Automation can improve efficiency and standardization but can also propagate errors rapidly when interfaces or rules are incorrect.
- Interface validation should evaluate the complete data pathway rather than only whether two systems can communicate.
- Laboratories need processes for exception handling, downtime, monitoring, maintenance, and change control.

## Discussion Prompts

- What information must be preserved when a microbiology instrument transmits a result to the LIS?
- How could an interface error affect results even when the analyzer itself is functioning correctly?
- What should be tested before an automated microbiology workflow goes live?
- What new risks can be introduced when previously manual processes become automated?
